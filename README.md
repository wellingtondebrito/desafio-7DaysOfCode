# 🚀 7DaysOfCode - HTML & CSS

Este repositório contém os desafios do **#7DaysOfCode** propostos por [Giovanna Moeller](https://www.linkedin.com/in/giovannamoeller/), onde aprimorei minhas habilidades em **HTML**, **CSS** e **JavaScript** ao longo de 7 dias, construindo uma **Landing Page de Vagas de Tecnologia**.

## 📌 Estrutura do Projeto
Em cada dia do desafio, foi criada uma **seção específica** da página, utilizando fundamentos de **HTML** e **CSS**. Além disso, implementei uma **animação em JavaScript** na seção de **métricas** para melhorar a interatividade.

### 🛠 Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox e Grid)
- JavaScript (para animação de métricas)

## 📂 Estrutura do Desenvolvimento
- **Dia 1** - Criando a Navbar com Flexbox
- **Dia 2** - Estruturando o Hero Section
- **Dia 3** - Desenvolvendo a Seção metrícas (com animação em JavaScript)
- **Dia 4** - Seção de vagas abertas
- **Dia 5** - Estruturando uma seção de comentários
- **Dia 6** - Estrutura da newsllater
- **Dia 7** - Finalização e Melhoria de Estilos(Falta finalizar)

   ```bash

   ```
2. Acesse a pasta do projeto:
   ```bash
   cd 7daysOfCode-HTML-CSS
   ```
3. Abra o arquivo `index.html` no navegador.
